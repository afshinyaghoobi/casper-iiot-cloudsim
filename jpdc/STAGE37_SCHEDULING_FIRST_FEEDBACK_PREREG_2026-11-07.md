## Predeclared scheduler hypothesis and controls (before results)
Create `jpdc/feedback_deadline_scheduler.py` and a separate exact source clone `jpdc/independent_physical_feedback_deadline_stage37.py` of the original Stage23 Python strict-FCFS physical engine. Original Stage6 PRED_GREEDY and CASPER_FULL must have **bitwise-equivalent JSON outputs** to the frozen Stage6 simulator for same calibration, count, scenario and seed. The three new policies are:
1. `NEW_CPU_FEEDBACK_ONLY`: per-node 75th percentile of POSITIVE service-time prediction errors after at least four actual CPU finishes, last32 finished CPU errors; network penalty zero.
2. `NEW_E2E_FEEDBACK_ONLY`: per-node 90th percentile of positive network delay EXCESS (actual E2E-delivered network minus nominal predicted), last32 delivered E2E outcomes, minimum eight (reuse frozen Stage6 `NetworkResidualRisk`'s `penalties()` for E2E-only).
3. `NEW_CPU_E2E_FEEDBACK`: add both penalties (no independent probability or safety certification).

At each dispatch, compute original predicted latency for all 21 nodes. Let `g` be original PRED_GREEDY argmin with node-index tie-break. For task MISSION choose nodes whose **NOMINAL** predicted latency is <=pred[g]+2ms; for HIGH/NORMAL use <=pred[g]+5ms. Within eligible candidates, choose argmin lexicographically of (indicator corrected prediction exceeds deadline, corrected prediction, nominal prediction, index), where corrected prediction=nominal+CPU penalty+E2E penalty. If **every candidate** exceeds deadline, still minimize corrected prediction; do not claim hard-deadline safety. The budgets of 2/5ms and minimum sample counts are unvalidated predeclared engineering hypotheses. Do not read hidden affected-node map, actual future CPU, future network, postshock index or oracle phase at dispatch. CPU labels enter policy only at CPU finish; network labels only at E2E feedback. No probing, no rerouting existing jobs. No learned uncertainty 'certificate'. Different baselines / ablations share physical stochastic task generation.

# JPDC independent Python discrete-event queue engine — Stage 1 protocol (2026-11-04)

## Scientific boundary, registered before execution
This is the **first runnable independent physical execution engine**, with event-time dynamics generated entirely inside Python. It is NOT a completed independent CASPER policy evaluation or a substitute for CloudSim/YAFS. The original frozen E42 Git blob `34256ca7bff46f911cf20e8b94278fbd09175746` and E4.6 remain unchanged. The prior independent Java-vs-Python chronological-FCFS physical queue fidelity criterion stays **FAILED** at 9.1214009ms >5ms; CloudSim SpaceShared directly admitted task 10901 ahead of previously queued task 10900. This new engine explicitly defines and tests its **own strict FIFO semantics** rather than claiming identical CloudSim behavior.

## Stage-1 model
- Zero import of CloudSim or original Java-generated task/node/decision traces. Independently recreate original Java RNG stream with `jpdc/independent_workload_generator.py`. Native Python priority event heap: arrivals and completions; simultaneous events resolve **completion before arrival**, then task index. Each node is an independent nonpreemptive single-server FCFS with FIFO waiting queue. At finish, the oldest queued task starts before any subsequent arrival. No mid-service preemption.
- Three *baseline-only* routing policies `CLOUD_ONLY` (nodes18..20), `EDGE_FIRST` (nodes0..11), and `PRED_GREEDY` (all21) use independently generated nominal latency. The mapped predicted backlog uses separately implemented `VirtualQueue`, periodically reset from the *independent* physical model's actual queue expected next-free time every 50ms; selected node predicted next-free is advanced by nominal service at each dispatch.
- Physical nominal service = work/capacity*12 milliseconds; nominal network = RTT+(input+output)*8000/bandwidth milliseconds. Network latency is added to end-to-end completion measurement but is not part of the VM CPU queue. No stochastic service jitter or hidden compute/network shock at this stage. Delay = (service completion time − original task arrival) + nominal network. This is a **deterministic clean-room baseline engine**.
- Fixed test matrix before execution: independent scientific seed indices **50 and 51**, scenarios `S0_STATIONARY`, `S1_LAMBDA_X2`, 12,000 original task records per seed×scenario, each of three baseline policies; **144,000 tasks across twelve independent physical simulations**, each with 21 nodes. The original baseline *names* and candidate sets are mirrored, but NO CASPER adaptive health/certification is evaluated in Stage 1.

## Must-pass gates
1. Unit fixtures: two-arrival FIFO non-overlap; same-time completion-before-arrival; multiple nodes execute in parallel; strict FIFO rescue for a pre-existing waiting task on completion; forbid negative/NaN durations and out-of-order original arrivals.
2. Per-run: every task exactly once arrived/routed/started/finished, no negative waits, no VM overlap, per-node start sequence equals dispatch FIFO order, exact conservation of 12k tasks, no task completions unaccounted for, no post-finish arrivals. End-to-end latency decomposes into nominal network + FCFS waiting + nominal CPU service within floating-point tolerance.
3. Deterministic rerun on the same seed/scenario/policy must yield byte-identical normalized report. Report full results for every seed/scenario/policy, no filtering or cherry-picking.
4. Test deliberately malformed input rejected; retain results JSON and provenance on failure.

## Limitations
**No claim of independent CASPER scheduler performance, calibrated certificate coverage, actual hidden-shock response, cross-simulator equivalence, or statistically significant policy superiority.** Stage 2 should add original nominal service randomness/physical shock and independently recomputed calibration from the engine's own outcomes, then full CP/E17/health feedback and *prespecified unseen seed-level* policy comparisons. Do not use Stage-1 baseline results as JPDC efficacy claims. Original 10-seed S2/S3 holdout p=.0625 and exploratory 4-seed factorial p=.125 remain nonsignificant.

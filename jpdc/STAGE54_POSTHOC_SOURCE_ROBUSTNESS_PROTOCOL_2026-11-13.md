## Fixed methodology before robustness output
Inputs: Stage52 complete original `audit.json` from artifact `jpdc-stage52-audit-only-recovery-original-source-cohort` (run 43369267053). Check exact eight seeds 1101–1108, both scenarios S2 and S3, both queue controls (`QUEUE_PRESSURE_05`, `QUEUE_PRESSURE_E2E_05`) vs `CASPER_FULL`, all 739 dependent MISSION tasks/scenario and exact integer per-seed miss differences from frozen audit.

Four posthoc contrasts: S2 queue-only minus FULL, S2 queue+E2E minus FULL, S3 queue-only minus FULL, S3 queue+E2E minus FULL. Sign convention: positive = queue method worse. Exact two-sided sign p excluding ties already calculated in original Stage52 audit; verify independently from integer deltas. Apply **Holm familywise adjusted p** to these 4 explicitly correlated exploratory contrasts, reporting the resulting p values (do not apply to covert candidate selection). No claim of confirmatory correction: the family itself is chosen retrospectively.

Compute exact **leave-one-source-seed-out** paired mean delta for each of 8 deletions; report min and max plus which deletions change effect sign. This diagnoses source sensitivity, not new independence. Separately produce deterministic paired source-seed nonparametric bootstrap percentiles (2.5%,97.5%) for mean missed-task difference per seed with **20,000 draws**, each draw resampling eight source units together with replacement using `random.Random(20261113)`, keeping matching policy and FULL outcomes within a seed; use nearest-rank percentile index at `ceil(prob * B)-1` in sorted values. Bootstrap is posthoc descriptive with small-n/discrete caveat, not a distribution-free certainty.

Use only source-seed n=8 and never treat the 739 task count as independent. Require signed-difference list exactly 8 long, original audit eight unique seeds, denominators/aggregates consistent, finite valid p, equal FULL denominators, no fabricated task-level pairing. Return complete machine-readable JSON and deterministic rerun byte-identical. The original Stage52 S2 prospective no-harm gate FAILURE remains whatever adjusted posthoc p values show.

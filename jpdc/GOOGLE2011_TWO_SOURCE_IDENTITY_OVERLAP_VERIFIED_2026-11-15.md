## Scientific inference, implications, boundaries
**Verified empirical observation** in 2 ×1024 deliberately selected original Borg datacenter source rows: significant source-key overlap is present despite non-overlapping sampled time intervals. **This does not demonstrate independence OR prove causal or workload-population dependence**, but it **falsifies the naive assertion** that different file indices and disjoint observed timestamps are by themselves a sufficient check for mutually exclusive `job_id` and `(job_id,task_index)` identities.

**Design implication:** Before any source-time split, specify how source identifiers map over the entire original trace, compare observed IDs across train/DEV/holdout, and use job-disjoint source grouping or explicit causal/time-block embargo when applicable. File prefixes alone cannot certify whole-trace job-disjointness. Avoid treating 2048 source event rows or two files as two independent IIoT benchmark source seeds. If underlying source identifiers can be recycled or anonymized, additional publisher documentation or whole-trace audit is needed before interpreting same-key occurrences as same physical jobs.

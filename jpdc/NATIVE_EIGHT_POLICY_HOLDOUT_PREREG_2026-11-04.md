## PREDECLARED primary endpoint and single hypothesis
**Primary contrast:** CASPER_FULL vs PRED_GREEDY only. For each seed s and scenario c, calculate the *post-change* (task index >=10000) MISSION deadline-miss rate, using the policy's `post_deadline_miss_rate` (deadline miss if completed end-to-end latency exceeds task's original deadline). The same original post-change task cohort is generated for all eight policies per seed/scenario, but its realized completion differs by policy. Define paired benefit:
`D_s = 0.5 * [(missRate_Greedy(s,S2) - missRate_Full(s,S2)) + (missRate_Greedy(s,S3) - missRate_Full(s,S3))]`.
Positive D means CASPER_FULL **fewer misses**. This equal weights S2/S3 and treats **each seed as one independent paired unit**. All 10 seed results enter regardless of direction; no posthoc seed exclusions.
**Primary inference:** exact TWO-SIDED sign test on the 10 D values (ties D exactly zero removed from sign count; report n_nonzero, pos, neg and ties). Exact p = min(1, 2*sum_{k=0}^{min(pos,neg)} C(n_nonzero,k)/2^n_nonzero). Family-wise alpha 0.05 (only ONE registered primary comparison). If all D=0 => p=1. Report arithmetic mean D, median D and all ten D values, both scenario-specific rates; never treat multiple tasks as independent observations or alter ties tolerance to fish significance. No superiority claim from positive effect if p >= .05. Report paired bootstrap 95% percentile interval of mean D with **10,000 resamples, Python random.Random(20261104)** as supplementary descriptive uncertainty only, not to override exact sign p.

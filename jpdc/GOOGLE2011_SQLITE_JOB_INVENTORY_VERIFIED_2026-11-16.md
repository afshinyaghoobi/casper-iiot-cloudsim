## Scientific status and limits
SQLite source presence index is a technically valid component for eventually checking overlap in candidate train/DEV/test windows, **but** does **NOT yet** retain complete per-task *attempt lifecycle* transitions, cross-file source causal ordering, absence of missing events, probabilistic sampling frame, complete 500-file original source trace, date block embargo, real task service time, network traffic, application deadline or industrial IIoT measurements. One source file cannot test real cross-file job independence. Synthetic two-file tests are explicitly labeled synthetic only. Not a new research algorithm, not a new source-seed or paper efficacy replication.

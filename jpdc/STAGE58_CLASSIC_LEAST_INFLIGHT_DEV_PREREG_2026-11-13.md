# Stage58 preregistration — published-classic least-connections executable baseline (2026-11-13)

**Scope:** Distinct causal and reproducible *conventional load-balancing controls*, not original Wu et al. (2026) DFAQ-LB reproduction and not a novel CASPER algorithm. The original 2026 FGCS article explicitly describes min-number-of-connections as a traditional static load balancing rule; see DOI 10.1016/j.future.2026.108460, and prior exact method fidelity Stage57 report. The author DFAQ-LB's elastic queue forecasting, multidimensional health, and migration are NOT implemented. Do not claim they are.

## Frozen algorithms before development outcomes
Inputs at each dispatch event are the current causal event simulator's **21 per-node running indicators plus waiting-queue lengths**, all maintained by engine from already submitted/finished tasks; nominal capacities specs[j][1] are static known machine data. No hidden failed-node mask, actual future arrivals/completions, realized service before finish, or feedback from future. Original routing candidates all 21 nodes. Task arrival/priority/deadline is not used for the baseline choice.

- `LEAST_INFLIGHT`: select argmin `(pending[j], j)`, `pending[j] = int(running[j] is not None)+len(queues[j])`. This is a causal single-task non-preemptive minimum-outstanding-job-count adaptation of classic least-connections. If equal counts, lowest ID wins. No predictive task cost.
- `CAPACITY_WEIGHTED_LEAST_INFLIGHT`: select argmin `((pending[j]+1.0)/capacity[j], j)`. The +1 is a **predeclared proxy for including the arriving job**; exact original Wu or any other author method not claimed. Known capacity is `specs[j][1]`; no predicted latency or task work used in score.

These are conceptually **different** from PRED_GREEDY's argmin predicted end-to-end latency and Stage57 rejected Online-MCT alias. Test deterministic fixtures showing disagreement from PRED_GREEDY, no alteration to source arrival stream, queue conservation, strict FIFO queue per node, finite positive capacities and nonnegative integer counts. Original Stage44 and Stage6 sources and E42/E4.6 all immutable. Modify only isolated Stage58 simulator clone and tests, runner, workflow. Preserve all negative outcomes.
